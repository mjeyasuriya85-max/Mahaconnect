# MahaConnect
### One Platform. Connected Government Services.

MahaConnect is a proposed unified digital platform designed to make government services easier for citizens to discover, access and track.

## About the Project

Citizens often need to visit multiple portals to access different government services. MahaConnect aims to simplify this experience through a single digital platform.

## Key Features

- Citizen Login and Dashboard
- Government Service Discovery
- Online Application Submission
- Application Status Tracking
- Digital Document Wallet
- AI-Based Scheme Recommendations
- Government Service Assistant Chatbot
- Multi-language Support (English and Tamil)
- Notifications and Updates
- Admin Dashboard
- OTP Verification

## Technologies Used

**Frontend**
- HTML5
- CSS3
- JavaScript

**Backend**
- Node.js
- Express.js
- SQLite

**Other Technologies**
- Twilio Verify
- Git and GitHub

## Project Structure

- frontend/ - User interface and web pages
- backend/ - Server, API routes and database
- frontend-backup/ - Backup frontend files

## Installation and Setup

1. Clone the repository:

   git clone https://github.com/mjeyasuriya85-max/Mahaconnect.git

2. Open the project:

   cd Mahaconnect

3. Install backend dependencies:

   cd backend
   npm install

4. Configure the required environment variables.

5. Start the backend using the start command configured in package.json.

## Project Objective

To explore how a unified digital platform can improve access to government services through technology, secure data sharing and intelligent assistance.

## Important Note

MahaConnect is an independent academic project and prototype concept. It is not an official government platform and does not represent an existing government integration.
